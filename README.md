# 🗺️ GenAI / LLMs Roadmap

Ruta de aprendizaje pública, en 9 fases, para construir — de forma aplicada — desde los fundamentos hasta arquitecturas de agentes en producción. La comparto en abierto como parte de mi serie **Bitácora AI Engineer**.

> **EN:** A public, hands-on roadmap from Python fundamentals to production-grade agentic architectures, shared as part of my *Bitácora AI Engineer* series on [LinkedIn](https://linkedin.com/in/diegoferrua) and [YouTube](https://youtube.com/@diegoferrua).

## 📓 El notebook

Todo el contenido vive en [`GenAI_LLMs_Roadmap.ipynb`](./GenAI_LLMs_Roadmap.ipynb): explicaciones, ejemplos de código ejecutables y ejercicios, fase por fase. Está pensado para seguirse en orden, pero cada fase es autocontenida si ya tienes base en alguno de los temas.

## 🧭 Las 9 fases

| Fase | Tema | Estado |
|---|---|---|
| 0 | Base de Python aplicada — tipado (`typing`, Pydantic), APIs REST/HTTP profesional, Async y concurrencia real | ✅ Publicada |
| 1 | Fundamentos de LLMs — cómo funcionan, tokens, APIs de modelos (OpenAI, Anthropic, etc.) | 🔜 Próximamente |
| 2 | Prompting avanzado y salidas estructuradas (structured outputs) | 🔜 Próximamente |
| 3 | Embeddings y bases de datos vectoriales | 🔜 Próximamente |
| 4 | RAG (Retrieval-Augmented Generation) de punta a punta | 🔜 Próximamente |
| 5 | Fine-tuning y evaluación de modelos | 🔜 Próximamente |
| 6 | Agentes y function/tool calling | 🔜 Próximamente |
| 7 | Frameworks multi-agente — LangGraph, MCP y orquestación | 🔜 Próximamente |
| 8 | LLMOps — observabilidad, costos y monitoreo en producción | 🔜 Próximamente |
| 9 | Proyecto final — arquitectura de agentes en producción, de punta a punta | 🔜 Próximamente |

*(El orden y alcance exacto de las fases 1-9 puede ajustarse a medida que avanza la ruta.)*

## 🚀 Cómo usarlo

1. Clona el repo o abre el notebook directo en [Google Colab](https://colab.research.google.com/github/Diegoferrua/genai-llms-roadmap/blob/main/GenAI_LLMs_Roadmap.ipynb).
2. Sigue las fases en orden — cada una construye sobre la anterior.
3. Corre los ejemplos de código vos mismo; el aprendizaje aplicado es el punto central de esta ruta.
